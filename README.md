# BanJoco - Sistema de Banca Móvil

Proyecto de software desarrollado de forma individual como parte de la formación académica en **Ingeniería en Sistemas Computacionales** en el **Tecnológico de Estudios Superiores de Jocotitlán (TESJo)**.

## Descripción del Proyecto
BanJoco es una aplicación web diseñada para simular operaciones básicas de banca móvil, permitiendo a los usuarios gestionar su cuenta, consultar saldos, realizar movimientos y mantener un control seguro de sus transacciones financieras.

## Tecnologías Empleadas
* **Backend:** PHP
* **Frontend:** HTML, CSS, JavaScript.
* **Base de Datos:** MySQL / PostgreSQL
* **Entorno de Pruebas:** MAMP
