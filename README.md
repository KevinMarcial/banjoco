#  BanJoco - Sistema de Banca Móvil

Aplicación web que simula operaciones bancarias, con gestión de cuentas, movimientos financieros y distintos perfiles de usuario

##  Descripción y Funcionamiento
BanJoco es una aplicación web diseñada para simular operaciones de banca móvil con un entorno realista y completo. El sistema cuenta con dos perfiles de acceso (**Cliente** y **Administrador**) que permiten gestionar cuentas, consultar saldos, realizar movimientos y mantener un control seguro de las transacciones financieras. 

Entre sus capacidades principales destaca la **generación de estados de cuenta**, permitiendo que tanto el cliente pueda consultar su historial financiero personal como el administrador pueda supervisar y auditar los reportes del sistema.

##  Pasos de Instalación y Ejecución
1. **Descargar los archivos:** Obtén el código fuente del proyecto en tu equipo.
2. **Abrir en VS Code:** Carga la carpeta del proyecto dentro de Visual Studio Code para su revisión o edición.
3. **Configurar el entorno:** Instala y abre **MAMP o MAMP PRO**.
4. **Activar servicios:** Enciende los servidores de **Apache**, **Nginx** , **MySQL** , **Memcached** , **Redis**  desde el panel de control.
5. **Verificar la base de datos:** Ingresa a **phpMyAdmin** para comprobar que las tablas y la base de datos del sistema estén cargadas correctamente.

## Tecnologías Utilizadas
* **Backend:** PHP
* **Frontend:** HTML, CSS, JavaScript
* **Base de Datos:** MySQL / PostgreSQL
* **Entorno de Pruebas:** MAMP / MAMP PRO
